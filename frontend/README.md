# 議会のミカタ 京都 (Kyoto Politician Tracker)

京都市会における議員の政策質疑ログおよび本会議での議決賛否データを構造化し、政策論戦の「密度」と「個性」をAIで可視化するシビックテック・オープンデータプラットフォームです。

発言回数や文字数といった形式的な数値による「格付け（通信簿）」ではなく、各議員がどのようなエビデンスや対案を持って市政課題に向き合っているかを可視化し、市民と議員の政策的なマッチングを支援することを目的としています。

---

## 🌟 主な機能

1. **市議会マクロ論戦マップ**
   * 京都市会で交わされた全質疑スレッド（5,000件超）を分野別に分類し、議論の集中度と「賛否が分かれた激論議案」の分布を俯瞰。
2. **議員別 4軸ポリシーパラメータ**
   * 各議員の質疑アプローチを「根拠・データ」「対案・是正」「地域解像度」「議論の進展」の4軸レーダーチャートで可視化。
   * 議場での注力分野や質疑の特徴を客観的要約で提示。
3. **質疑スレッド構造化ビュー**
   * 単なる発言の切り抜きではなく、「議員の質問 ➔ 行政答弁 ➔ 議員の再質問」を一連の対話（スレッド）として結合し、文脈を保持した状態で閲覧可能。
4. **本会議 議決・賛否データ（激論議案フォーカス）**
   * 全会一致の事務的案件を除外した「賛否が分かれた議案」を中心に、各会派および無所属議員の評決態度を記録。
   * AIによる争点解説（対立の核心、賛成派・反対派それぞれの論理）を併記。
5. **議員ポリシー徹底比較モード**
   * 最大3名の議員を選択し、4軸レーダーの重ね合わせ、注力政策ポートフォリオ（発言時間配分）、共通論点での直接突き合わせ、および激論議案における議決一致率を多角的に比較。

## 📐 AI評価ロジックと採点基準（Methodology）

本プラットフォームでは、客観性と公平性を担保するために以下の技術仕様およびルーブリックを採用しています。

### 1. 4つの客観的評価軸（ルーブリック）

各質疑スレッドは、党派性や政策の賛否から独立した以下の4指標（各0〜5点）で機械的に採点されます。

| 評価軸 | 0点（基礎水準） | 3点（標準水準） | 5点（高度水準） |
| :--- | :--- | :--- | :--- |
| **根拠・データ**<br>*(Evidence)* | 主観的な感想や感情的主張、伝聞のみ。 | 予算額、過去の実績、他都市事例などのファクトを引用。 | 条例条文、公的統計、一次資料、監査結果を明確に提示。 |
| **対案・是正策**<br>*(Solution)* | 単なる批判や抽象的な要望のみ。 | 実務上検討可能な改善策や選択肢を提示。 | 財源・制度設計を含む対案の提示、**または行政の瑕疵を突き是正・見直しを約束させた追及**。 |
| **地域解像度**<br>*(Local Focus)* | 国政レベルの抽象論や一般論に終始。 | 特定の区、局・事業名、制度運用上の課題に言及。 | 町名、学区、商店街、公共施設、路線名など生活現場の具体名に深く言及。 |
| **議論の進展**<br>*(Constructive)* | 原稿の棒読みに終始し、答弁内容を無視。 | 行政答弁を踏まえ、論点を絞り込んで再質問。 | 答弁の矛盾を突き、調査・再検討の言質を引き出すなど議論を前進させた展開。 |

### 2. アルゴリズムの中立性と再現性

* **決定論的出力の担保:** 評価モデル（Google Gemini）の生成パラメータ `temperature` を **`0.0`** に固定し、同一スレッドに対して常に同一の採点結果が出力される再現性を確保しています。
* **属性情報の遮断:** 議員の所属会派、当選回数、年齢、性別などの属性情報は評価用プロンプトから完全に排除し、全スレッドに対して同一のプロンプトを適用しています。

## 🏛️ データソースとクレジット

本プロジェクトは、以下の一次情報源およびオープンデータ基盤を利用しています。

1. **一次情報源:**
   * [京都市会 公式会議録検索システム](https://www2.city.kyoto.lg.jp/shikai/)
   * 京都市会 本会議 審議結果（議決結果データ）
2. **政治議論データ基盤:**
   * [Sagebase (セージベース)](https://sage-base.com/)
   * 会議録の発言構造化、人物同定データを利用しています。
   * ライセンス: [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/deed.ja)

## ⚠️ 免責事項・運営ポリシー

* **非党派性・中立性:** 本プラットフォームは特定の政党、政治団体、候補者を支持または批判するものではありません。
* **測定範囲の限界:** 本ツールの分析対象は「京都市会の議場および委員会室内で記録された公式会議録」に限定されています。市民相談・陳情対応、地域活動、政策勉強会など、**議場外における重要な議員活動・実績は本ツールの測定範囲外**です。

* **Frontend:**
  * React 19
  * Vite
  * Tailwind CSS
  * Recharts (レーダーチャート・データビジュアライゼーション)
  * Lucide React (アイコン)
* **Data Pipeline:**
  * Python 3.10+
  * BeautifulSoup4 / lxml (Webスクレイピング・2次元グリッド正規化)
  * Requests
  * Google Gemini API (スレッド構造化およびルーブリック採点)

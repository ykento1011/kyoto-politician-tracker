## 市民にとっての変更

神戸の縦長の全情報カードを、京都と同じ「公約名・現況・重要な未確認・原典導線」の一覧と根拠詳細へ分ける。市長写真と5段階は保持し、登録段階を達成済みとは扱わない。未確認予算は0円にせず、金額と未確認理由を詳細に保持する。

神戸を最初に選んだ理由は、既存JSONにM01/M02の未確認・集計外・財源未確認と、M01の別記録としての予算案source_checked区分が明示されていること。資料の充実度を推定して選んだのではない。M03〜05の登録値は変更せず、画面では根拠確認中として扱う。

BudgetEvidence・ReportIssueButtonを再利用する。神戸の表示投影では確認区分のない従来予算を「未確認」とし、財源はverifiedだけ表示する。元のJSON・値・区分は書き換えない。URLは都市の正確なHTTPS authorityに限り、明示ポート・userinfo・類似ホストを拒否。リンク切れ登録は有効リンクにしない。公式リンクの外部応答／PDF頁ジャンプは未検証。

台帳 `mayor-evidence-inventory.json` は40政策すべてに行を持つ。原典参照186件（同一資料の政策別参照を含む）。施策枝は必要箇所に付け、P-04医療費と保育料、P-14精神医療とAYAを分離。保存CAS索引参照、原文／政策対応、既存審査、公開受入は別欄。索引参照だけを新規原本／receipt直接検証とは数えない。台帳は文書でありブラウザーにimportしない。
